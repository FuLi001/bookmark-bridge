Bookmark Bridge 1.0.0 使用说明
================================

一、它会同步什么
----------------

Bookmark Bridge 在同一台 Mac 上双向同步：

  Safari：书签 > 个人收藏 > 你的文件夹和网页
  Chrome：书签 > 书签栏 > 你的文件夹和网页

两个浏览器自己的根目录不会被复制或改名，因此不会出现“个人收藏”套在
“书签栏”里面的额外层级。

不会同步 Safari 阅读列表、Chrome 其他书签、移动设备书签或浏览历史。
所有通信仅在本机 127.0.0.1:17315 进行，不上传云端，也不需要 NAS。


二、系统要求
------------

  - macOS 13 或更高版本
  - Safari
  - Google Chrome
  - Apple 芯片和 Intel Mac 均可运行


三、首次安装
------------

1. 解压压缩包。

2. 将整个“Bookmark Bridge 1.0.0”文件夹移动到“应用程序”目录。
   请先移动再安装 Chrome 扩展，之后也不要移动或删除扩展目录。

3. 按住 Control 点击“Bookmark Bridge.app”，选择“打开”。
   本软件是个人制作的本地自签名应用，没有经过 Apple 公证，因此首次打开
   可能出现安全提示。若仍被拦截，请前往：

     系统设置 > 隐私与安全性 > 安全性 > 仍要打开

4. Bookmark Bridge 启动后只显示在屏幕顶部菜单栏，图标是一个书签。

5. 点击菜单栏图标，选择“打开完全磁盘访问权限设置”。在列表中添加或开启
   Bookmark Bridge。若已经开启但仍提示无权限，请关闭开关再重新打开，
   然后退出并重新启动 Bookmark Bridge。

6. 在 Chrome 地址栏输入：

     chrome://extensions

   开启右上角“开发者模式”，点击“加载已解压的扩展程序”，选择安装包内的：

     Bookmark Bridge Chrome Extension

   Chrome 需要保持该扩展启用。扩展图标显示“!”时，通常表示桌面程序没有运行。


四、首次同步
------------

建议先分别导出 Safari 和 Chrome 书签作为额外备份。

等菜单栏中出现 Safari 和 Chrome 的书签数量后，根据实际情况选择：

  - 初始化：安全合并两边
    推荐首次使用。保留两边独有项目，同一文件夹内相同网址只保留一份。

  - 初始化：采用 Safari
    用 Safari“个人收藏”的内容调整 Chrome“书签栏”。

  - 初始化：采用 Chrome
    用 Chrome“书签栏”的内容调整 Safari“个人收藏”。

确认两边内容正常后，勾选“自动双向同步”。


五、同步速度与运行条件
----------------------

  - Chrome 修改后，通常约 1 至 4 秒同步到 Safari。
  - Safari 修改后，通常约 2 至 6 秒同步到 Chrome。
  - Chrome 后台扩展被系统休眠或 Mac 刚从睡眠中恢复时，最长可能约 30 秒。
  - 点击菜单栏中的“立即检查”可以手动触发一次 Safari 检查。

资源使用方式：Safari 书签每 3 秒进行一次本地只读比较；Chrome 通过一个空闲的
本地等待连接接收变更。内容没有变化时不会改写任何书签文件。

Bookmark Bridge 必须运行。Safari 不需要一直开启；Chrome 关闭时无法立即执行
同步，重新打开 Chrome 后会补同步。Mac 睡眠期间同步暂停，唤醒后继续。

建议前往：

  系统设置 > 通用 > 登录项

将 Bookmark Bridge 添加为登录时打开的项目。


六、冲突与备份
--------------

每次写入 Safari 前都会备份完整的 Safari 书签文件；向 Chrome 发出修改前也会
保存 Chrome 书签栏的 JSON 备份。点击菜单栏中的“打开备份目录”即可查看。

默认备份位置：

  ~/Library/Application Support/BookmarkBridge/Backups

如果 Bookmark Bridge 离线期间两边都被分别修改，程序不会猜测该保留哪边，
而是暂停自动同步并显示冲突。请检查两边后选择：

  - 解决冲突：采用 Safari
  - 解决冲突：采用 Chrome
  - 初始化：安全合并两边

“采用”会让另一边调整为所选浏览器的内容；不确定时优先使用安全合并。


七、更新与卸载
--------------

更新桌面程序后，macOS 可能需要重新授权完全磁盘访问权限。更新 Chrome 扩展后，
请在 chrome://extensions 页面点击该扩展的刷新按钮。

卸载步骤：

1. 从 Chrome 扩展管理页面移除 Bookmark Bridge。
2. 退出菜单栏中的 Bookmark Bridge。
3. 删除“应用程序”中的 Bookmark Bridge 文件夹。
4. 按需删除备份目录和系统设置中的完全磁盘访问权限记录。

卸载不会删除 Safari 或 Chrome 中现有的书签。
